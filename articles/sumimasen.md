日本に来て、いちばんよく聞くことばは何ですか？ 「すみません」と答える留学生は多いはずです。

電車で人にぶつかったら「すみません」。道で{親切|しんせつ}にしてもらったら「すみません」。レストランで店員さんを呼ぶときも「すみませーん！」。

あやまるとき、お礼を言うとき、人を呼ぶとき。まったくちがう場面なのに、同じことばを使うのはなぜでしょう？

## 「すみません」の3つの顔

まずは、どの「すみません」がどんな気持ちなのか、クイズで{確|たし}かめてみましょう。

```quiz
タイプ: 4択
問題: 先生に「宿題を忘れてしまって、すみません」。この「すみません」は、どんな気持ち？
○ あやまる気持ち
× ありがとうの気持ち
× 人を呼びたい気持ち
× 断りたい気持ち
解説: これはいちばんわかりやすい「おわび」の「すみません」。「申し訳ありません」と言うと、もっとていねいになります。
```

```quiz
タイプ: 4択
問題: エレベーターで、知らない人がドアを開けて待っていてくれた。思わず「あ、すみません」。どんな気持ち？
× あやまる気持ち
○ ありがとうの気持ち
× 人を呼びたい気持ち
× 断りたい気持ち
解説: 中心にあるのは「ありがとう」の気持ち。でも、「わたしのために待たせてしまった」という、少し申し訳ない気持ちもまざっています。ここがポイントです！
```

```quiz
タイプ: 4択
問題: レストランで手をあげて「すみませーん！」。どんな気持ち？
× あやまる気持ち
× ありがとうの気持ち
○ 人を呼びたい気持ち
× 断りたい気持ち
解説: 店員さんを呼ぶ「すみません」。「ちょっといいですか」と話しかけるときの前置きとしても使えます。
```

## ナゾを解くカギは「済む」

「すみません」を漢字で書くと「**済みません**」。もとの動詞は「{済|す}む」です。

「済む」には「終わる」「問題がなくなる」という意味があります。「用事が済む」「お金を払って済む」のように使いますね。

つまり「すみません」は、もともと「**このままでは、わたしの気持ちが済まない（終わらない）**」という意味なんです。

- 相手に{迷惑|めいわく}をかけた → このままでは済まない → **おわび**
- 相手が何かしてくれた → お返しをしないと済まない → **お礼**
- 相手の時間をもらって話しかける → 済まない → **呼びかけ**

3つの場面に共通しているのは、「**相手に{負担|ふたん}をかけてしまった**」という気持ちです。だから、1つのことばでぜんぶ言えるんですね。

```words
済む | すむ | 終わる。問題がなくなる
負担 | ふたん | 相手にとって大変なこと、重いこと
前置き | まえおき | 本当に言いたいことの前に言うことば
```

## 「ありがとう」とどうちがう？

お礼の「すみません」と「ありがとう」。どちらを使えばいいのでしょう。

「ありがとう」は**うれしい気持ち**に、「すみません」は**相手の負担**に注目したことばです。目上の人に親切にしてもらったときは、「**すみません、ありがとうございます**」と両方言うと、とても自然に聞こえます。

```quiz
タイプ: めくる
問題: 仲のいい友達が、ジュースをおごってくれました。何と言うのが自然？
答え: 「ありがとう！」
解説: 親しい友達に「すみません」と言うと、少しかたくて、距離があるように聞こえます。友達どうしなら「ありがとう！」「サンキュー！」がぴったりです。
```

```point
「すみません」の中心にあるのは「相手に負担をかけた」という気持ち。**あやまる・お礼・呼びかけ**の3つは、ぜんぶこの気持ちから生まれています。
```

ちなみに、会話では「**すいません**」と発音する人も多いです。どちらも同じ意味ですが、書くときは「すみません」と書きましょう。
